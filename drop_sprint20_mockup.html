— DETALLE DE BOOKING · WORKFLOW

ESTADOS

★ NUEVO → LEÍDO → ⏱ COTIZADO → ✓ AGENDADO
o desde cualquier paso: ✗ RECHAZADO

Cada cambio de estado se loguea en el contact_interactions (auditoría). El paso "agendado" auto-crea evento en /calendario con monto + estado pago=pendiente.

— FOLLOW-UP AUTOMÁTICO

RECORDATORIO INTELIGENTE

Cuando un booking pasa a estado COTIZADO, el sistema crea automáticamente un follow-up para 3 días después con la nota:

"Recontactar [Venue] - cotizado $X sin respuesta"

El follow-up aparece en /dashboard + push notification. Si el booking pasa a AGENDADO o RECHAZADO antes, el follow-up se cierra automático.
